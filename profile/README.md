<h1 align="center">Mercantir</h1>

<p align="center"><strong>Your next customer might not use a browser.</strong></p>

Mercantir keeps orders, stock, customers and product knowledge as one system rather than four, built on sovereign open source (the Open Mercato framework). The product data is structured so that a question can be answered precisely — by a person today, and by whatever is asking on their behalf later.

## What it does

- **Order management**, stock and warehouse in one place.
- **One customer record** across every channel.
- **Product knowledge, not product pages**, on one data platform.
- **Recommendations from context.** Pay for value, not licences.

## For Microsoft 365

- **[Mercantir for Power Platform](https://mercantir.com/microsoft-power-apps)** — a free version of Mercantir built on Microsoft Power Apps (a model-driven app) and Microsoft Dataverse, installed into your own Microsoft Power Platform environment, with the data staying there.
- **[Mercantir Code](https://mercantir.com/microsoft-power-apps-code)** — the same data in an interface designed for Mercantir, built as a Microsoft Power Apps code app.
